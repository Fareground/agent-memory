# Security Policy

## Reporting a vulnerability

Please report security issues privately to **sandro@corza.ai** — do not open a
public issue. Include a description, reproduction steps, and the affected
version. You will get an acknowledgement within a few days, and a fix or
mitigation plan before any public disclosure.

## Supported versions

Only the latest minor release receives security fixes. Upgrade to the newest
`0.x` release before reporting issues against older versions.
